#  Sports Tournament Performance Analysis

A Python + pandas project that analyses match and ball-by-ball data to explore team and player performance.

##  Datasets
- `matches.csv` – match details (`team1`, `team2`, `winner`)
- `deliveries.csv` – ball-by-ball data (batter, bowler, runs)

##  Features
- View the first *N* matches
- Search matches played by any team, with the winner
- Search a batter to see total runs and sample deliveries

##  Tech Stack
Python, pandas, Google Colab / VS Code
